## 3. Key Architectural Deliverables

### 3.1 Comprehensive Anti-SSRF & Prohibited Hostname Engine (`packages/common/scope`)
- **Cloud Metadata Blocking:** Unconditionally rejects AWS (`169.254.169.254/32`), AWS Container Credentials (`169.254.170.2/32`), GCP, Azure, Oracle (`169.254.169.254`), and Alibaba (`100.100.100.200/32`) metadata targets.
- **Metadata Hostnames:** Added explicit rejection of prohibited hostnames: `metadata.google.internal`, `instance-data`, `localhost`.
- **Link-Local & ULA IPv6:** Strictly blacklisted IPv6 link-local (`fe80::/10`) and unique local address ranges (`fd00::/8`).
- **Multi-Homed DNS Rebinding Defense:** Validates all resolved addresses returned for multi-homed domain targets. Rejects target fail-closed if any single resolved IP falls into a prohibited range.

### 3.2 Target Authorization & Multi-Tenant Scope Engine (`packages/common/scope`)
- **Tenant Target Manifest:** Added `TenantTargetManifest` struct and `PolicyForTenant()` constructor to construct deterministic, hardened scope policies per tenant.
- **Wildcard Subdomain Dot Boundaries:** Strictest wildcard subdomain enforcement requiring explicit `.` boundaries (e.g., `*.example.com` matches `sub.example.com` but strictly rejects apex `example.com` without explicit permission and prevents lax/tld wildcards like `*`, `*.com`, `*example.com`).
- **Configurable Resolver Support:** Added `DefaultResolver` to support isolated mocking during offline CI and automated testing.

### 3.3 Worker Daemon Pre-Execution Scope Verification (`apps/worker/internal/daemon`)
- **Authoritative Pre-Execution Guard:** Enforced `scopePolicy.Validate()` in `daemon.process()` before syncing state or claiming execution leases, and in `orchestrator.executeScannerAttempt()` before creating workspaces or provisioning containers.
- **Zero Host Footprint on Rejection:** Out-of-scope or prohibited targets are aborted immediately without creating disk directories or launching containers.
- **Diagnostic Metrics:** Automatically records `ViolationNetwork` and `CauseNetwork` metrics on target scope/SSRF violations.

### 3.4 Adapter Scope Enforcement & Finding Filtration (`apps/worker/internal/adapters`, `scopevalidator`)
- **OCI Scanner Scope Bounds:** `NewOCINucleiRunnerWithScope` and `NewOCIZAPRunnerWithScope` enforce scope bounds prior to container execution.
- **Multi-Field Target Extraction:** `scopevalidator.Validator` parses target references across `asset`, `url`, `host`, `endpoint`, `uri`, `ip`, and `target_url`, with robust port stripping.
- **Finding Quarantine:** Findings that pivot to or reference prohibited destinations or out-of-scope endpoints are quarantined and stripped from the report.
- **Audit Diagnostics:** Generates `OUT_OF_SCOPE_TARGET_REJECTED` diagnostic events detailing the dropped finding and violation reason.
