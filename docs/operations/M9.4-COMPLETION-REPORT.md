## 3. Key Architectural Deliverables

### 3.1 Ephemeral Execution Token System (`apps/worker/internal/egress/token.go`)
- **Per-Execution Ephemeral Tokens:** Cryptographically random per-job tokens bound to `JobID`, `TenantID`, `AssessmentID`, and `Scanner`.
- **Thread-Safe Token Manager:** `TokenManager` provides token issuance, validation, and per-job bulk revocation upon completion.
- **Proxy Authentication Guard:** In `proxy.serveHTTP`, validates execution token before processing CONNECT tunnels or forwarding HTTP requests.
- **407 Challenge:** Unauthenticated, expired, or invalid tokens fail-closed with HTTP `407 Proxy Authentication Required` and `X-Kelvin-Egress-Blocked: true`.

### 3.2 Destination & Port Verification Engine (`apps/worker/internal/egress/policy.go`, `proxy.go`)
- **Default-Deny Policy Lockdown:** Outbound requests fail-closed if no protocol or port is explicitly approved for the scanner.
- **Destination Verification:** Evaluates destination IP and hostname against approved assessment target scope before dialing.
- **Telemetry & Alarm Metrics:** Automatically records `ViolationNetwork` and `CauseNetwork` metrics on destination, port, or protocol violations.
- **403 Forbidden Rejections:** Returns HTTP `403 Forbidden` with detailed diagnostic error on policy violations.

### 3.3 Anti-OAST & Outbound Bypass Prevention (`apps/worker/internal/egress/policy.go`)
- **Comprehensive OAST Blacklist:** Expanded `knownCallbackSuffixes` to unconditionally block major public OAST providers:
  - `interactsh.com`, `interact.sh`
  - `oast.fun`, `oast.live`, `oast.site`, `oast.online`, `oast.pro`, `oast.me`
  - `canarytokens.com`, `canarytokens.org`
  - `ceye.io`, `dnslog.cn`
  - `burpcollaborator.net`
  - `webhook.site`, `pipedream.net`
  - `requestbin.net`, `requestbin.com`
  - `ngrok.io`, `ngrok-free.app`, `localtunnel.me`, `beeceptor.com`
- **Config Tampering Prevention:** `ValidateConfig()` rejects configuration containing callback or tunneling directives.

### 3.4 Container Network Namespace Egress Wiring (`apps/worker/internal/sandbox`, `daemon`)
- **Environment Proxy Wiring:** In `oci.go` and `executor.go`, configures `HTTP_PROXY`, `HTTPS_PROXY`, `http_proxy`, `https_proxy`, `ALL_PROXY`, `all_proxy`, `NO_PROXY`, and `no_proxy`.
- **Orchestrator Token Injection:** The orchestrator automatically provisions the egress proxy, generates an execution token, and injects the authenticated proxy URL (`http://token:<token>@127.0.0.1:port`) into `task.EgressProxy` and `spec.EgressProxy`.
- **Default Network Isolation:** When network is disabled, containers strictly use `--network=none` with zero network access.
