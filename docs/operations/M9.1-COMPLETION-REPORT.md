## 2. Key Architecture & Security Deliverables

1. **Distributed Lease Locking (ADR-M9-01):**
   - Implemented `AcquireLease`, `RenewLease`, `ReleaseLease`, and `IsLeaseActive` in `packages/common/queue`.
   - Utilizes atomic Lua scripts for renewal and release to eliminate split-brain dual-worker container execution.
   - Guarded `XAutoClaim` so competing workers never steal jobs held by active leases.

2. **Authoritative JobEnvelope Contract (Schema Version 2):**
   - Created `packages/common/queue/envelope.go` with strict schema validation.
   - Enforces UUID bounds, target address presence, deadline validation, and UTC expiration checks (`ErrJobExpired`).
   - Seamless Version 1 backward compatibility for legacy messages.
   - Worker daemon unpacks and validates envelopes before scanner invocation, failing closed immediately on invalid or expired envelopes.

3. **Database State Synchronization & Observable Diagnostics:**
   - Implemented `StateSyncer` interface with `PostgresStateSyncer` (tenant RLS transaction synchronization) and `MemoryStateSyncer`.
   - Guaranteed that job transitions (`RUNNING`, `COMPLETED`, `CANCELLED`, `FAILED`) persist to the database without silent divergence.
   - Added HTTP diagnostics server (`:8081/healthz`, `:8081/readyz`) with system and adapter probes.
   - Background worker vitality heartbeats maintain the `worker:{worker_id}` key in Redis.
   - 5-second graceful shutdown fallback context ensures terminal states persist even when `SIGINT`/`SIGTERM` is received.

4. **Hardened Systemd Packaging & Operational Runbook:**
   - Hardened `deploy/staging/kelvin-worker.service` with strict process isolation (`ProtectSystem=strict`, `ProtectHome=true`, `PrivateTmp=true`, `NoNewPrivileges=true`, `CPUQuota=200%`, `MemoryMax=2G`).
   - Automated local verification harness in `scripts/test-worker-local.sh`.
   - Full operational runbook in `docs/operations/WORKER_DEPLOYMENT_RUNBOOK.md`.
