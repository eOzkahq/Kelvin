## 3. Key Architectural Deliverables

### 3.1 Pinned Scanner Container Identity & Release Manifest Lock
- **Pinned Nmap Certification:** Pinned image `ghcr.io/eozkahq/kelvin/scanner-nmap:7.95` (`sha256:4a38dfc6d996e382d3345f1bce8b33534a029a242f3ea99d5a6b0c2a7e75e114`) added to `deploy/scanners/images.lock.json` and `deploy/scanner-image-lock.yaml`.
- **Approved Scanners and Executables Allowlist:** Added `/usr/bin/nmap` and `/zap/zap-full-scan.py` to `approvedExecutables` and `approvedScanners` in `sandbox.ProcessInvocation`.
- **Sandbox Security Spec Invariants:** All container runners configure `PIDsLimit: 256`, dropping privileges, read-only root filesystems, and unprivileged user mapping.

### 3.2 Containerized Nmap Adapter & XML Report Parser (`apps/worker/internal/adapters/nmap_report.go`, `nmap_adapter.go`)
- **Normalized XML Parser:** Parses Nmap `-oX` XML output stream safely. Uses `parserguard.ValidatePayload` to reject null bytes, oversized payloads, and invalid UTF-8.
- **Envelope Compliance:** Converts parsed ports and NSE script results into canonical findings envelopes, ensuring `"vulnerability": {}` mapping and strict schema compliance.
- **Service Classification:** Identifies plaintext and high-risk services (e.g. Telnet, unencrypted FTP) and flags CBC ciphers with CWE-327.
- **Execution Argument Synthesis:** Enforces bounded port ranges (`-p 1-1024` default), safe rates (`--max-rate 50`), and host timeouts (`--host-timeout 60s`).

### 3.3 Nuclei Profile Controls & Bounded Execution (`apps/worker/internal/adapters/nuclei_adapter.go`)
- **Safe Web Assessment Profile (`ProfileSafeWeb`):** Added `kelvin.profile.safeweb.v1` profile with tags `safe,web,exposure`, strictly excluding `dos,fuzz,intrusive,sqli,rce`, with rate-limit 2 req/s and concurrency 1.
- **Profile Argument Mapping:** Dynamically resolves rate limits, concurrency, tags, and excluded tags for `standard`, `deep`, and `safeweb` profiles.
- **Output Streaming:** Reads JSONL findings line-by-line through memory-safe parsers.

### 3.4 OWASP ZAP Baseline & Active Scanner Hardening (`apps/worker/internal/adapters/register_mvp.go`, `scannerprocess/invocation.go`)
- **Mode Discrimination:** Automatically selects between `zap-baseline.py` and `zap-full-scan.py` based on profile and authorization gates.
- **Active Scanning Authorization Gate:** Rejects active scan invocations fail-closed unless explicitly authorized under an approved active profile with administrative sign-off (`ProfileDeep`).
- **Proxy Wiring:** Automatically connects ZAP daemon and spiders to the worker's controlled egress proxy.

### 3.5 Truthful Readiness Diagnostics & Capability Matrix (`apps/worker/internal/readiness/`, `adapters/adapters.go`)
- **Host OCI Image Inspector:** `OCIImageInspector` inspects local container runtime storage (`podman image inspect`) and verifies digest match against release locks.
- **Actionable Diagnostics:** Missing or unpulled images report `StatusUnavailable` with clear actionable remediation advice.
- **Synchronized Registry Availability:** `Checker` dynamically updates `adapters.Registry` availability and `CapabilityMatrix()` snapshot.
- **Pre-Lease Acquisition Guard:** Worker daemon verifies scanner readiness *before* acquiring distributed Redis execution leases, preventing unrunnable jobs from blocking leases fail-closed.
